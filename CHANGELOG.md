# 2.1.0

## 1. Добавлена возможность кликабельности на всю карточку.
   Если надо указывать, что по карточке можно кликнуть, то в `settings` пишем `clickable: true` и в самой карточке сам обработчик: `onClick: () => {...}`
   Выглядит это так:

```ts
add({
    //... другие параметры
    settings: {
        //... другие параметры
        clickable: true, // опициональное поле, boolean
    },
    onClick: () => console.log("Клик"), // опициональное поле, () => void
});
```
### Важно! 
Если не передано хотя бы одно из значений, то клик не обрабатывается

## 2. Теперь в ```id``` добавлен префикс "omni-"
Сдеално это для того, чтобы, когда не передан ```message_id``` в ```id```, не путать реальный ```message_id``` с сгенерированным внутри пакета

Выглядит это так:
```ts
add({
      id: `omni-${createId()}`, // message_id
      //... другие параметры
})
```
